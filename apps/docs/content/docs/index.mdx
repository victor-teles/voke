Voke is a framework for creating, testing, building, and synthesizing Hono-compatible APIs and related serverless Functions from a config-first project model.

The core idea is simple: describe work as **Functions**, collect them in a **Function Registry**, expose route-backed Functions through a **Gateway**, and keep deployment settings in `voke.config.ts`.

## Why Voke exists

Serverless projects often drift across framework config, handler files, local test harnesses, and deployment templates. Voke keeps those decisions explicit:

- `voke.config.ts` is the project source of truth.
- `defineFunction()` declares a named serverless compute unit.
- `defineFunctions()` creates the typed registry used by project code.
- `createGateway()` exposes route-backed Functions over HTTP.
- `voke synth` produces a direct CloudFormation template.

## The mental model

```ts
import {
  api,
  createGateway,
  defineFunction,
  defineFunctions,
  Voke,
} from "voke";
import config from "../voke.config";

const app = new Voke();

const functions = defineFunctions({
  routes: defineFunction({
    routes: [
      app.get("/health", {
        handler: () => ({ ok: true, service: config.name }),
      }),
    ],
  }),
});

const gateway = createGateway({ config: { ...config, functions } });
export default api(gateway, { config });
```
