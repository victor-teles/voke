Voke is a TypeScript-first AWS Lambda framework for creating, testing, building, and synthesizing route-backed APIs and related serverless Functions from a config-first project model.

The core idea is simple: describe work as **Functions**, collect them in a **Function Registry**, expose route-backed Functions through a **Gateway**, and keep deployment settings in `voke.config.ts`.

## Why Voke exists

Serverless projects often drift across framework config, handler files, local test harnesses, and deployment templates. Voke keeps those decisions explicit:

- `voke.config.ts` is the project source of truth.
- `fn()` declares an invokable serverless compute unit.
- `http()` declares a route-backed Function from Route Builder routes.
- `createFunctions()` creates the typed registry used by project code.
- `voke(functions)` exposes route-backed Functions over HTTP.
- `voke synth` produces a direct CloudFormation template.

## The mental model

```ts
import { createFunctions, http, route, voke } from "voke";
import config from "../voke.config";

const functions = createFunctions({
  http: http({
    routes: [
      route.get("/health", {
        handler: () => ({ ok: true, service: config.name }),
      }),
    ],
  }),
});

export default voke(functions, { config });
```
