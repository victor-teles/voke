## Three commands

```bash
voke create my-api
cd my-api
bun run deploy
```

`voke create` writes a working API, runs `bun install`, and prints the next steps. In between, run it locally and test it:

```bash
bun run dev     # local API on http://localhost:3000
bun test
```

`bun run deploy` runs `voke deploy --stage dev`: it needs AWS credentials (a profile, SSO login, or environment credentials) and prints the API URL when it finishes. `bun run remove` deletes the stage. Run `voke doctor` when something is missing; it checks Bun, the config, the project and your AWS credentials.

The packages are not published yet, and the published names (`voke`, `@voke/*`) are not final.

## What `voke create` generates

```txt
my-api/
  voke.config.ts       # project settings and the Provider: provider: aws()
  src/index.ts         # the Functions and the Gateway
  src/routes/health.ts # GET /health
  test/api.test.ts     # a test through @voke/testing
  package.json         # dev, test, deploy and remove scripts
  README.md
  .gitignore
```

`provider: aws()` in `voke.config.ts` is what makes `deploy`, `synth` and `local` work: the Provider is set only there.

## Manual setup

Inside an existing project, add `voke.config.ts`:

```ts
import { defineConfig } from "voke";
import { aws } from "@voke/aws";
import { dynamodbTable, sqsQueue } from "@voke/aws/cloudformation";

export default defineConfig({
  name: "hello-api",
  provider: aws(),
  stage: "local",
  region: "us-east-1",
  entrypoint: "./src/index.ts",
  resources: {
    usersTable: dynamodbTable({ partitionKey: "id" }),
    eventsQueue: sqsQueue(),
  },
});
```

## Define an API

Create route-backed Functions and mount them in a Gateway:

```ts
import { createFunctions, http, route, voke } from "voke";
import config from "../voke.config";

const functions = createFunctions({
  http: http({
    routes: [
      route.get("/", {
        handler: () => ({ message: "Hello from Voke" }),
      }),
      route.get("/health", {
        handler: () => ({ ok: true, service: config.name }),
      }),
    ],
  }),
});

const gateway = voke(functions, { config });

export default gateway;
```

## Run local checks

Use the project gates while developing:

```bash
bun test
bun run typecheck
bun run release:check
```

For local HTTP behavior, call the Gateway directly from tests:

```ts
const response = await gateway.request("/health");
```

## Build and synthesize

```bash
voke build ./src/index.ts ./dist
voke synth ./src/index.ts ./dist/cloudformation.json --config voke.config.ts
```

## Deploy

With AWS credentials configured and `provider: aws()` in `voke.config.ts`:

```bash
voke deploy --stage dev
```

Voke prints the API URL when the deploy finishes. Remove the stage with `voke remove --stage dev`. See the deploy guide for details.
