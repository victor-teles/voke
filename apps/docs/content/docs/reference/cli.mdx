## Help and version

```txt
Voke v0.0.0

Usage: voke <command> [options]

Commands:
  voke build    Bundle the project's Functions through the Provider.
  voke create   Create a new API project and install its dependencies.
  voke deploy   Build and deploy a stage through the Provider.
  voke dev      Run the API locally with hot reload.
  voke doctor   Check the toolchain, the project and the Provider.
  voke local    Run the Provider's local environment. The Provider may accept more flags.
  voke migrate  Generate a Voke skeleton from a Serverless Framework service.
  voke remote   Generate Remote Function Registry modules from remotes.
  voke remove   Delete a deployed stage through the Provider.
  voke synth    Write the Provider's deployment template.

Run voke <command> --help for its flags. voke --version prints the version.
```

`voke <command> --help` (or `voke help <command>`) prints a command's usage and flags. `voke --version` prints the version. An unknown flag is an error that suggests the closest flag:

```txt
$ voke synth --stag prod
Invalid CLI usage: Unknown flag --stag for "synth". Did you mean --stage?
Usage: voke synth [entrypoint] [out] [--config voke.config.ts] [--name api] [--stage local] [--region us-east-1]
```

## Development

```bash
voke dev [entrypoint]
```

Starts the local development workflow for the configured entrypoint.

## Build

```bash
voke build [entrypoint] [outdir]
```

Builds an ESM bundle of the entrypoint for the AWS Lambda Node.js runtime and writes a `package.json` with `"type": "module"` next to it. Modules matching `build.external` stay out of the bundle; the default, `["@aws-sdk/*"]`, uses the AWS SDK that ships with the Lambda runtime. Set `build.external: []` to bundle everything.

## Project starter

```bash
voke create <name> [directory] [--no-install] [--force]
```

Creates an API project in `./<name>` (or `directory`), runs `bun install`, and prints the next steps. The `package.json` name is exactly `<name>`, scope included. A non-empty directory is refused unless `--force`, which overwrites the starter files and keeps every other file.

## Doctor

```bash
voke doctor [--config voke.config.ts]
```

Prints one `ok`, `warn` or `fail` row per check: the Bun version, the config, the entrypoint, the discovered Functions and routes, the Provider, and the Provider's own checks (for `aws()`: credentials with the account id and region, and the local container tool). Exits non-zero when any row fails. Credentials are never printed.

## CloudFormation

```bash
voke synth [entrypoint] [out] --config voke.config.ts
```

Synthesizes the CloudFormation template for the configured project.

## Deploy and remove

```bash
voke deploy [--stage dev] [--region us-east-1] [--config voke.config.ts] [--dry-run]
voke remove [--stage dev] [--region us-east-1] [--config voke.config.ts] [--yes]
```

`voke deploy` builds the project, uploads it, and deploys the stage through the configured Provider, then prints the outputs (API URL first) and writes `.voke/outputs/<stage>.json`. `--dry-run` previews the changes without applying them. The stage `local` is reserved for the local emulator.

`voke remove` deletes the stage after you type its stack name to confirm; `--yes` skips the prompt and is required outside a terminal.

## Local AWS

```bash
voke local start
voke local bootstrap --name hello-api --stage local
voke local stop
voke local reset
```

Runs the local workflow of the configured Provider. With `aws()`, this is Floci unless you pass another Local AWS Provider: `aws({ local: ... })`.

## Remote code generation

```bash
voke remote generate
voke remote generate users
```

Fetches runtime-exposed Function Contract metadata from configured remotes and writes generated Remote Function Registry modules. Without a name, Voke generates every configured remote. With a name, Voke generates only that remote.

## Serverless migration

```bash
voke migrate serverless [serverless.yml] --out ./voke-migration
```

Generates a Function-first migration skeleton and report from Serverless Framework config.
