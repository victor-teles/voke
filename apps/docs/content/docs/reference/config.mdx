---
title: Config Reference
description: The core fields in voke.config.ts and how they shape build, runtime, and CloudFormation output.
---

`voke.config.ts` is the source-controlled configuration file that drives Voke project workflows.

```ts
import { defineConfig } from "voke";

export default defineConfig({
  name: "hello-api",
  stage: "local",
  region: "us-east-1",
  entrypoint: "./src/index.ts",
});
```

## Core fields

Each setting has exactly one spelling.

| Field                | Purpose                                                                          |
| -------------------- | -------------------------------------------------------------------------------- |
| `name`               | Service name used for generated resource names and deployment commands.          |
| `stage`              | Deployment stage, such as `local`, `dev`, or `prod`. Falls back to `VOKE_STAGE`. |
| `region`             | AWS region for synthesized and deployed resources.                               |
| `entrypoint`         | Project entrypoint; synth and build import it to discover the Functions.         |
| `provider`           | The Provider, such as `aws()` from `@voke/aws`. Required for synth and build.    |
| `resources`          | Infrastructure resources, such as `sqsQueue()` from `@voke/aws/cloudformation`.  |
| `environment`        | Environment variables set on every deployed Function.                            |
| `build`              | Bundle `entrypoints`, `outdir`, and `external` modules (AWS SDK by default).     |
| `cloudFormation.out` | Where `voke synth` writes the template.                                          |
| `runtime`            | `timeout` (seconds) and `memory` (MB) for every Function.                        |
| `remotes`            | Remote Function Registry targets for local cross-project invocation.             |
| `api.name`           | Name of the HTTP API. Defaults to `name`.                                        |
| `api.cors`           | Browser cross-origin access: `true` or `{ origins, methods, headers, ... }`.     |
| `dev`                | `voke dev` entrypoint and environment overrides.                                 |

The config file must use a default export: `export default defineConfig({ ... })`.

## Defaults

A freshly deployed stack needs no tuning. These defaults apply unless you set the value:

| Setting                | Default                                   | Where to change it                                              |
| ---------------------- | ----------------------------------------- | --------------------------------------------------------------- |
| Function timeout       | 15 seconds                                | `runtime.timeout`; per Function `synthesis.timeout`             |
| Function memory        | 1024 MB                                   | `runtime.memory`; per Function `synthesis.memory`               |
| HTTP CORS              | off                                       | `api.cors`                                                      |
| Lambda Node.js runtime | `nodejs22.x`                              | `aws({ lambda: { runtime } })`; per Function `awsLambda()`      |
| Lambda architecture    | `arm64`                                   | `aws({ lambda: { architecture } })`; per Function `awsLambda()` |
| Log retention          | 14 days                                   | `aws({ lambda: { logRetentionDays } })`                         |
| SQS visibility timeout | 6 × the consumer's timeout + batch window | `sqsQueue({ visibilityTimeoutSeconds })`                        |

```ts
// voke.config.ts
import { aws } from "@voke/aws";
import { sqsQueue } from "@voke/aws/cloudformation";
import { defineConfig } from "voke";

export default defineConfig({
  name: "orders",
  provider: aws({ lambda: { runtime: "nodejs24.x", logRetentionDays: 30 } }),
  runtime: { timeout: 20, memory: 512 },
  api: { cors: { origins: ["https://app.example"], credentials: true } },
  resources: { jobsQueue: sqsQueue({ visibilityTimeoutSeconds: 180 }) },
});
```

Override one Function where it is declared, in the project entrypoint:

```ts
import { awsLambda } from "@voke/aws";
import { fn } from "voke";

export const report = fn({
  synthesis: { timeout: 120, provider: awsLambda({ architecture: "x86_64" }) },
  handler: () => ({ ok: true }),
});
```

Voke checks the AWS limits when it builds the model: memory 128–10240 MB, timeout 1–900 seconds,
and at most 30 seconds for a Function with HTTP routes (the API Gateway HTTP API integration
limit). An explicit queue visibility timeout lower than a consumer's timeout is an error.

`api.cors: true` allows any origin, method and header without credentials. With
`credentials: true`, list explicit `origins`. The same value configures the local Gateway
(`voke dev`, `gateway.request(...)`) and the deployed HTTP API.

## Resource bindings

CloudFormation resources can be bound into runtime code:

```ts
import { bindResource, createAwsClientConfig } from "@voke/aws";

const usersTable = bindResource("usersTable", "name");
const dynamoConfig = createAwsClientConfig();
const tableName = usersTable.value();
```

## Remotes

Use `remotes` in the consuming Voke Project to centralize runtime targets for generated Remote Function Registries:

```ts
import { defineConfig } from "voke";

export default defineConfig({
  name: "wallet",
  remotes: {
    users: {
      targets: {
        local: "http://localhost:3001",
      },
    },
  },
});
```

The selected target defaults contract metadata discovery to `<target>/_voke/contract`. Set `contract` only when metadata is published somewhere else:

```ts
export default defineConfig({
  name: "wallet",
  remotes: {
    users: {
      out: "./src/generated/users.remote.ts",
      targets: {
        local: {
          origin: "http://localhost:3001",
          contract: "http://localhost:3001/_voke/contract",
        },
      },
    },
  },
});
```
