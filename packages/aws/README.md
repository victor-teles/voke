# @vokejs/aws

The AWS Provider for Voke: CloudFormation synthesis, Lambda handlers, deploy, local AWS and diagnostics.

Part of [Voke](https://github.com/victor-teles/voke). Every Voke package is released at the same version as `voke`.

```bash
bun add voke @vokejs/aws
```
