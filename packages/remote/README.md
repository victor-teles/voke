# @voke/remote

Typed Remote Function Registries for calling Voke Functions across projects.

Part of [Voke](https://github.com/victor-teles/voke). Every Voke package is released at the same version as `voke`.

```bash
bun add voke @voke/remote
```

See the [Voke README](https://github.com/victor-teles/voke#readme) for usage. Licensed under MIT.
