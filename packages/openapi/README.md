# @vokejs/openapi

OpenAPI 3.1 documents and a Scalar API reference page for Voke routes.

Part of [Voke](https://github.com/victor-teles/voke). Every Voke package is released at the same version as `voke`.

```bash
bun add voke @vokejs/openapi
```

Documentation:

- [OpenAPI and API reference](https://github.com/victor-teles/voke/blob/main/apps/docs/content/docs/guides/openapi.mdx)
